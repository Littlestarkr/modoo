# 모두의 창업 작성기

제2기 모두의 창업 프로젝트 제출 서류를 작성하는 웹페이지 2종입니다.

- `modoo-plan.html` : 1R 사업계획서 (Q1 문제 인식 · Q2 실현 가능성 · Q3 성장전략 · Q4 향후 발전방안)
- `modoo-report.html` : 1R 활동보고서 (1:1 멘토링 · 창업활동자금 · AI 솔루션, 붙임1 집행 상세내역)

참고자료 업로드(PDF·docx·텍스트) 또는 텍스트 입력 후 작성 버튼을 누르면 양식에 맞춘 초안을 만들고 Word(.docx)로 저장합니다.

두 페이지는 Claude 아티팩트 실행 환경(`window.claude`: AI 작성·파일 저장·계정별 저장)에서 동작하도록 만들었습니다.
일반 웹호스팅(GitHub Pages 등)에서 열면 AI 작성과 계정 저장은 쓸 수 없고, 입력은 브라우저에만 저장됩니다.
